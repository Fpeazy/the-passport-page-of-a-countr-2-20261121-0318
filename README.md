The Passport Page of a Country That Isn't There. This program writes one image — an invented passport spread for the Republic of Caldra, held by Ash-Warden Dain Morvek — to `/output/entry.png`. An AI judge compares the images two at a time, and the 20 best win rates share $50.

## Run it

```sh
node main.ts
```

The program is stdlib-only (Node 22), deterministic, and writes a 1024x1024 PNG of at most 1 MiB to `/output/entry.png`.
